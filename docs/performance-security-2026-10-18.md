# 2026-10-18 加载与安全升级

范围为个人介绍站和南昌十五中纪念站的独立静态发布；不修改 GEOHOT 源码、部署、数据库、队列、采集开关及其既有缓存规则。

## 加载体验

- 个人站在通过原有省流量、2g/slow-2g 条件后，提前并行发现 Three.js 依赖与匹配设备的地球贴图；资源复用，不重复下载。语言菜单由用户打开后，只预取另一语言的已知同源页面。
- 纪念站漫游图片按当前帧与相邻帧加载，留言列表靠近该区域或直接导航后再获取；合并重复 GET，发帖/回复成功仍刷新新列表。
- 修复手机端漫游圆点负边距导致的命中区重叠，保留原有视觉、动画和键盘操作。
- 源站只对带八位十六进制发布版本的个人站宣传视频提供一年 immutable 缓存；裸视频地址仍使用四小时，保留 Range/206。补丁仅增加两处媒体 location，复制各自安全头，不改其他应用配置块。

## 安全边界

- 本地预览只开放公开页面和资源，拒绝私有 dot 路径、开发工具、非本机 Host、写方法及逃逸 symlink。合成假配置的 HTTP200 在修复后被拒绝；没有读取真实配置，也不代表曾确认线上公网泄露。
- 负向测试副本只复制允许的 Git 跟踪文件，不复制原 Git 配置、hooks 或 ignored 私有文件。共享 Git 对象仅用于可信本地 QA，不是恶意代码隔离沙箱或脱敏分享目录。
- 停用已完成的一次性旧路由迁移入口，避免覆盖现代发布及 GEOHOT 路由；现行发布保留精确 GitHub main 校验、原子切换、源站摘要核验和回滚。
